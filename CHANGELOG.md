# Changelog

## 1.0.0 - 2026-10-21

Initial KayelOS release.

### Included

- Debian 13 base
- DWM desktop environment
- QuickShell desktop/bar configuration
- KayelOS branding and system identity
- KayelOS Fastfetch artwork
- System-wide Nerd Fonts
- Calamares graphical installer
- Penguins' Eggs remaster/install integration
- KayelOS live installer launcher
- Dynamic GRUB greeting based on the installed user's name
- Curated /etc/skel defaults
- Git and classroom/development packages
